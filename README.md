# 🛒 Blinkit Sales & Performance Analysis Dashboard | Power BI

An interactive Power BI dashboard designed to analyze Blinkit's overall sales performance, customer satisfaction, inventory distribution, and item-level insights to identify key growth drivers and optimization opportunities.

---

## 📊 Overview

This project provides a comprehensive end-to-end data analysis solution for **Blinkit**, India's leading quick-commerce platform. The dashboard transforms raw operational and transactional data into actionable insights, helping business stakeholders track KPIs, optimize inventory allocation, and understand customer purchasing patterns.

---

## 🎯 Key Performance Indicators (KPIs) & Features

- **Total Sales Analysis:** Breakdown of overall revenue across product categories, outlet types, and locations.
- **Average Sales & Ratings:** Evaluation of average order value and customer satisfaction metrics per item type.
- **Inventory & Outlet Performance:** Comparative analysis between **Tier 1, Tier 2, and Tier 3** cities and establishment types (Supermarket vs. Grocery Store).
- **Fat Content Distribution:** Breakdown of sales performance between **Low Fat** and **Regular** product options.
- **Item Categorization:** In-depth view into top-performing categories (Fruits & Vegetables, Snack Foods, Household, Dairy, etc.).

---

## 🛠️ Tools & Technologies Used

- **Power BI Desktop:** Data transformation, DAX modeling, and visual dashboard creation.
- **Power Query:** Data cleaning, ETL, standardizing text inputs, and handling missing values.
- **DAX (Data Analysis Expressions):** Custom measures for dynamic KPIs (Total Sales, Average Rating, Item Count, etc.).
- **Data Source:** Blinkit transactional dataset (`.csv` / `.xlsx`).
